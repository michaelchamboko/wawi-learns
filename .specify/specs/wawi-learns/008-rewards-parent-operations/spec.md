# SLC-008 — Rewards and parent operations specification

**Requirements:** PRD-FR-020, PRD-FR-021, PRD-FR-026
**Depends on:** SLC-007

## Vertical scope

Deliver learning-only immediate/long-term rewards and the complete protected parent operation surface: evidence dashboard, explanations, safe overrides, custom packs, assisted activities, consent, export and verified deletion. Parent claims remain traceable to immutable evidence.

## Acceptance criteria

- **AC-SLC-008-001:** Collection, building and character progress derive from immutable reward events; errors never remove progress; intensity/reduced-motion controls work.
- **AC-SLC-008-002:** Dashboard reports every English/maths dimension, weak reason, baseline/window certainty, sync/pack state and evidence drill-down without overstating progress.
- **AC-SLC-008-003:** Parent overrides and activity controls change future plans but never fabricate evidence, erase attempts or bypass safety/decodability.
- **AC-SLC-008-004:** Custom packs and parent-assisted activities validate exact revisions before child access and use the private overlay when personalised.
- **AC-SLC-008-005:** Export, consent withdrawal and profile/account/generated-content deletion require the specified verification, clear/reject stale data and are proven end to end.

## Non-goals

No separate reward game, loss/shame streaks, multiple children, offline parent dashboard, remote device-management UI, advertising or medical/emotional labels.
